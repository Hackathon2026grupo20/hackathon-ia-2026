# Referências internas

`openmeteo_event_rules_legacy.json` é uma cópia do arquivo de regras presente no snapshot OpenMeteo de 2026-09-18 fornecido ao projeto.

Ele é mantido somente para rastreabilidade metodológica. **Não é a configuração ativa** do Predicta, pois as regras originais eram diárias e baseadas em localidades.
