# Motor 2 — boundary

O Motor 2 deve consumir **somente** `system_signal_v1` do Motor 1.

Ele não deve importar `motor_sin`, ERA5-Land, geometrias, usinas ou modelos de demanda.

Nesta entrega, a árvore está preparada e a fixture de `system_signal_v1` permite iniciar o desenvolvimento independente do parser tarifário e guardrails.
